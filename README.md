# PocketOS Breeze Dark

Android desktop shell inspired by KDE Plasma 6.4 Breeze Dark. Open this folder in
Android Studio and let Gradle sync. Build the APK with **Build > Build Bundle(s) / APK(s)
> Build APK(s)**; the debug APK appears at `app/build/outputs/apk/debug/app-debug.apk`.

The external-display desktop uses pixel-sized controls, a single Plasma-style panel,
four switchable workspaces, a Kickoff-inspired app launcher, and resizable centered
windows. Applications run as Android apps. PocketOS recreates the desktop experience in
Compose; it does not boot or run the KDE/Linux operating system itself.

The included icons come from the Breeze Icons project and are used under the terms in
`app/src/main/assets/breeze/LICENSE-icons.txt`.
